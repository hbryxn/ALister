# ALister

Turn a pile of clothing photos into eBay, Depop and Vinted listings, then track every piece to sold.

Open the app: https://hbryxn.github.io/resale-lister/

This repository holds the built web app only. Connect Claude with your own Anthropic API key (stored only in your browser, sent only to Anthropic), or use the claude.ai version with your Claude account. Your inventory and photos stay on your device.
