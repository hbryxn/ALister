# Resale Lister

Turn a pile of clothing photos into eBay, Depop and Vinted listings, then track every piece to sold.

Open the app: https://hbryxn.github.io/resale-lister/

This repository holds the built web app only. You need your own Anthropic API key (console.anthropic.com); it is stored only in your browser and sent only to Anthropic. Your inventory and photos stay on your device.
